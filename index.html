05 / UNDERSTAND THE QUESTION

The problem, without the hype.

Some problems are easy to check. Are they also easy to solve?

P contains problems a deterministic computer can solve in polynomial time. NP contains problems where a proposed yes-answer can be verified in polynomial time. The question is whether those two classes are actually the same.

A proof either way would need to withstand mathematical review. Restricted examples, experiments, and analogies help guide research, but none alone settles the question.
